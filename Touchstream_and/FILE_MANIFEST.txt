QUICK START:
------------

1. Extract archive:
   tar -xzf tapstream.tar.gz
   cd tapstream

2. Build desktop:
   cargo build --release
   cargo run

3. Build Android:
   ./build_android.sh

4. With IPTP:
   cp ../tapstream_iptp_extensions.go /path/to/IS_ITTP_Shell/
   # Integrate and rebuild IPTP shell
   iptp> tapstream build-desktop
